# 漂亮的编程字体

使用一个漂亮的字体会让人赏心悦目，下面我推荐的字体都是免费的。

我常用的英文字体有[cascadia-code](https://github.com/microsoft/cascadia-code)、 [FiraCode](https://github.com/tonsky/FiraCode) , [Hack](https://github.com/source-foundry/Hack) 、[JetBrains Mono](https://www.jetbrains.com/lp/mono/)、[nerdfonts](https://www.nerdfonts.com/font-downloads)，这些字体用于编写代码使用。

中文免费字体主要使用 [思源字体](https://github.com/adobe-fonts/source-han-sans/) 与 [阿里巴巴普惠体](https://alibabafont.taobao.com/)

> 目前使用的字体是 cascadia-code

## 安装配置

在vscode配置中搜索`Editor: Font Family` 并设置以下值。

```bash
"editor.fontFamily": 
    'JetBrains Mono ExtraLight',
    'Cascadia Code Light',
    '思源黑体 Light'
```

需要在配置中将连字打开（设置中搜索`fontLigatures`关键词）

```json
"editor.fontLigatures": true,
```
