# 日期时间

## 数据类型

| 日期时间类型 | 占用空间 | 日期格式            | 最小值              | 最大值               | 零值表示            |
| ------------ | -------- | ------------------- | ------------------- | -------------------- | ------------------- |
| DATETIME     | 8 bytes  | YYYY-MM-DD HH:MM:SS | 1000-01-01 00:00:00 | 9999-12-31 23::59:59 | 0000-00-00 00:00:00 |
| TIMESTAMP    | 4 bytes  | YYYY-MM-DD HH:MM:SS | 1970-01-01 08:00:01 | 2038-01-19 03:14:07  | 00000000000000      |
| DATE         | 4 bytes  | YYYY-MM-DD          | 1000-01-01          | 9999-12-31           | 0000-00-00          |
| TIME         | 3 bytes  | HH:MM:SS            | -838:59:59          | 838:59:59            | 00:00:00            |
| YEAR         | 1 bytes  | YYYY                | 1901                | 2155                 | 0000                |

- Mysql 保存日期格式使用 YYYY-MM-DD HH:MM:SS 的 ISO 8601 标准
- 向数据表存储日期与时间必须使用 ISO 格式

## 创建字段

```sql
alter table stu add  brithday datetime default null;
ALTER TABLE stu change brithday birthday datetime default null;
UPDATE stu set birthday = "2003-9-1 20:33:13" WHERE id =5;
```

### 实例操作

使用`Date_format`格式化日期与时间显示

```sql
select sname,DATE_FORMAT(birthday,'%Y年%m月%d日 %H时%i分%s秒') as birthday from stu;
SELECT sname,DATE_FORMAT(birthday,"%Y年%m月%d日 %h:%i:%s") FROM stu;
```

使用`time_format`格式化输出时间

```sql
select sname,TIME_FORMAT(birthday,'%r') as  birthday from stu;

SELECT sname,DATE_FORMAT(birthday,"%Y年%m月%d %h:%i:%s") FROM stu;
SELECT sname,TIME_FORMAT(birthday,"%h:%i:%s") FROM stu;
```

| 维度               | TIME_FORMAT()                                      | DATE_FORMAT()                                          |
| ------------------ | -------------------------------------------------- | ------------------------------------------------------ |
| **处理维度**       | 仅处理「时间部分」（时、分、秒、微秒）             | 处理「日期部分」（年、月、日）+ 可兼容时间部分         |
| **输入类型**       | 仅支持 `TIME`/`DATETIME`/`TIMESTAMP`（仅提取时间） | 支持 `DATE`/`DATETIME`/`TIMESTAMP`（完整日期 + 时间）  |
| **格式化符范围**   | 仅支持时间类格式化符（% H、% i、% s 等）           | 支持日期类（% Y、% m、% d 等）+ 时间类格式化符         |
| **输入无时间部分** | 返回 `NULL` 或空                                   | 仅格式化日期部分，不受影响                             |
| **使用场景**       | 仅需展示 / 处理时间（如 14:30:00）                 | 需展示 / 处理完整日期 + 时间（如 2025-12-31 14:30:00） |

## 时间戳

以时间戳格式来记录日期与时间

<b>设置TIMESTAMP字段</b>

```sql
ALTER TABLE stu ADD updateed_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP;
INSERT INTO stu SET sname = '数据库',uodated_at = "2025-12-31 13:48:00"
```

<b>添加数据时自动更新时间</b>

```sql
ALTER TABLE stu ADD update_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP
ON UPDATE CURRENT_TIMESTAMP;
```

当执行添加与更新时字段将自动为当前时间

```sql
insert into stu set sname = '张三';
update stu set sname='ih' where id =5;

ALTER TABLE stu ADD updated_at timestamp DEFAULT CURRENT_TIMESTAMP;
ALTER TABLE stu drop updated_at;
ALTER TABLE stu ADD updated_at timestamp DEFAULT CURRENT_TIMESTAMP on UPDATE CURRENT_TIMESTAMP;
UPDATE stu set sname = "赵云" WHERE id =2;
```

- 执行更新或添加都会改变`timestamp`字段

## 常用函数

下面时获取当前日期，时间的示例

```sql
SELECT now(),CURRENT_DATE(),CURRENT_TIME();
```

获取时间部分值

```sql
select YEAR(update_at),MONTH(update_at),DAY(update_at) FROM stu;
```

其他可以使用的函数如下

| 函数                                                         | 说明                                                         |
| ------------------------------------------------------------ | ------------------------------------------------------------ |
| HOUR(时间)<br />`HOUR('1990-01-01 07:00:00') → 7`            | 时（范围从 0 到 23 ）<br />`从一个时间里，把【小时】单独抠出来` |
| MINUTE(时间)<br />`MINUTE('23:59:59') → 59`                  | 分（范围从 0  到 59）<br />`从时间里，单独把【分钟】抠出来`  |
| SECOND<br />`SECOND('23:59:59') → 59`                        | 秒（范围从 0 到 59）<br />`从时间里，单独把【秒】抠出来`     |
| YEAR<br />`YEAR( '2000-05-20' )    --> 2000`                 | 年（范围从 1000 到 9999）<br />`从日期时间里，单独把【年份】抠出来` |
| MONTH<br />`MONTH( '2000-05-20' )    --> 5月，结果就是 5`    | 月（范围从 1 到 12）<br />`从日期里，单独把【月份】抠出来`   |
| DAY<br />`DAY( '2000-05-20' )   --> 20`                      | 日（范围从 1 开始）<br />`从日期里，单独把【几号】抠出来`    |
| TIME(日期时间)<br />`TIME('2025-12-30 15:45:22') -->15`      | 获取时间;<br />`从 日期 + 时间 里，只拿出 时：分: 秒，丢掉年月日` |
| WEEK<br />`WEEK('2025-12-30')   --> 结果是 52（12月底一般是第52周）` | 一年中的第几周，从 1 开始计数<br />`从日期里，取出这是一年中的第几周` |
| QUARTER<br />`QUARTER('2025-08-10')  → 3`                    | 一年中的四季，从 1 开始计数<br />`提取日期属于第几季度`      |
| CURRENT_DATE                                                 | 当前日期                                                     |
| CURRENT_TIME                                                 | 当前时间                                                     |
| NOW                                                          | 当前时间                                                     |
| DAYOFYEAR<br />`DAYOFYEAR('2025-02-01')  → 32`               | 一年中的第几天（从 1 开始）<br />`返回这一天是今年的第几天`  |
| DAYOFMONTH<br />`DAYOFMONTH('2025-12-30')  → 30`             | 月份中天数（从 1 开始）<br />`返回这一天是本月的第几天（几号）` |
| DAYOFWEEK<br />`DAYOFWEEK('2025-12-30')  --> 假如这天是星期二 → 返回 3` | 星期天（1）到星期六（7）<br />`返回日期是一周中的第几天`     |
| WEEKDAY<br />`WEEKDAY('2025-12-30')  --> 如果是星期二 → 返回 1` | 星期一（0）到星期天（6）<br />`WEEKDAY () 从 星期一开始算，从 0 开始编号` |
| TO_DAYS<br />`TO_DAYS('2025-12-30')  --> 得到一个巨大的数字：739949` | 从元年到现在的天数（忽略时间部分）<br />`把日期变成一个纯数字（总天数）` |
| FROM_DAYS<br />`FROM_DAYS(739949) -->2025-12-30`             | 根据天数得到日期（忽略时间部分）<br />`把一个【总天数】，还原成 日期` |

| TIMESTAMPDIFF(单位, 时间1, 时间2)                            | 根据指定单位计算两个日期时间的间隔(包括日期与时间);<br />`TIMESTAMPDIFF(单位, 时间1, 时间2)` |
| LAST_DAY<br />`LAST_DAY('2025-12-05')-->2025-12-31`          | 该月的最后一天<br />`给一个日期，返回这个月的最后一天是几号` |
| UNIX_TIMESTAMP<br />`UNIX_TIMESTAMP('2025-01-01 00:00:00')--> 1735728000` | 把字段（日期 / 时间）转换成 **Unix 时间戳**<br />`日期时间 → 转换成 Unix 时间戳` |
| FROM_UNIXTIME<br />`FROM_UNIXTIME(1735728000)--> 2025-01-01 00:00:00` | 时间戳 → 日期<br />`Unix 时间戳（一大串秒数） 转换成我们能看懂的 日期时间` |

### 拆分日期时间

```sql
SELECT YEAR(birthday),MONTH(birthday),DAY(birthday),
HOUR(birthday),MINUTE(birthday),SECOND(birthday) FROM stu;
```

### 当前日期时间

```sql
SELECT now(),CURDATE(),CURRENT_DATE(),CURRENT_TIME(),NOW();
```

### 时间计算

```sql
SELECT DAYOFYEAR(now()),DAYOFMONTH(now()),DAYOFWEEK(now()),WEEKDAY(now());
```

### 秒转换

不包含日期的秒转换

```sql
SET @time = time(now());
SELECT now(),TIME_TO_SEC(@time),SEC_TO_TIME(TIME_TO_SEC(@time));
```

日期时间与秒转换

```sql
SELECT NOW(),UNIX_TIMESTAMP(birthday),FROM_UNIXTIME(UNIX_TIMESTAMP(birthday)) FROM stu;
```

### 天转换

```sql
SELECT now(),TO_DAYS(birthday),FROM_DAYS(TO_DAYS(birthday)) FROM stu;
```

### 差值计算

`DATEDIFF(结束日期, 开始日期)  # 返回 结束-开始 的天数`

计算天数差值，忽略时间部分

```sql
SELECT now(),DATEDIFF(now(),birthday) from stu;
```

计算时间差值，忽略天数

`TIMEDIFF(A,B);计算 A - B 的时间差（时分秒）`

```sql
SELECT now(),TIMEDIFF(time(birthday),time(now())) from stu;
```

### 指定单位差值

`TIMESTAMPDIFF(单位, 开始时间, 结束时间)`

支持单位有`YEAR,MONTU,WEEK,DAY,HOUR,MINUTE,SECOND`等。下面时获取学生来到人生经历的天数

```sql
select sname,TIMESTAMPDIFF(day,birthday,NOW()) from stu;
```

```sql
SELECT TO_DAYS(NOW()),FROM_DAYS(TO_DAYS(NOW()));
SELECT DATEDIFF(NOW(),birthday) FROM stu;
SELECT TIMEDIFF(TIME(NOW()),TIME(birthday)) FROM stu;
SELECT TIMESTAMPDIFF(day,birthday,NOW()) FROM stu;
SELECT TIMESTAMPDIFF(month,birthday,NOW()) FROM stu;
SELECT TIMESTAMPDIFF(second,birthday,NOW()) FROM stu;
SELECT TIMESTAMPDIFF(minute,birthday,NOW()) FROM stu;
SELECT TIMESTAMPDIFF(WEEK,birthday,NOW()) FROM stu;
```



## 基本查询

`MYSQL`内部将日期按数值进行处理，下面时查找`1990-02-22 09:00:00`日期可以写成数值形式

```sql
SELECT * FROM users WHERE birthday = 1990222090000
```

查找在 1990 ~ 1999年出生的同学

```sql
SELECT * FROM stu WHERE birthday BETWEEN '1990-01-01' AND '1999-12-31';
```

获取年龄最大的同学

```sql
SELECT * FROM stu ORDER BY birthday ASC LIMIT 1;
# 更准确的查询
SELECT * FROM stu;
WHERE birthday=(SELECT birthday FROM stu ORDER BY birthday ASC LIMIT 1);
```

查询在  1 班 或 2 班 1990 年出生的同学

```sql
SELECT * FROM stu WHERE class_id IN(1,2) AND year(birthday)=1999;
```

90 后最喜欢上的班级

```sql
select count(id) as total,class_id from stu;
where left(birthday,4)>=1990 and year(birthday)<=2000
GROUP BY class_id
ORDER BY total DESC
LIMIT 1;
```

大于 20 岁的女生最多的班级

```sql
SELECT count(id),class_id FROM stu
WHERE TIMESTAMPDIFF(YEAR,birthday,now())>20 AND sex=2;
GROUP BY class_id
ORDER BY count(id) DESC
LIMIT 1;
```

## 时间计算

| 函数      | 说明                                                         |
| --------- | ------------------------------------------------------------ |
| ADDTIME   | 添加时间（负数为减少），只对时间有效                         |
| TIMESTAMP | 添加时间（负数为减少），只对时间有效                         |
| DATE_ADD  | 根据单位添加时间，支持单位有<br />YEAR/MONTH/DAY/HOUR/MINUTE/<br />SECOND/HOUR_MINUTE/DAY_HOUR/<br />DAY_MINUTE/DAY_SECOND/HOUR_MINUTE/<br />HOUR_SECOND（负数时等于 DATE_SUB) |
| DATE_SUB  | DATE_ADD的反函数                                             |
| LAST_DAT  | 指定月最后一天日期                                           |

七小时前的时间

```sql
SELECT ADDTIME(NOW(),'-7:00:00');
SELECT TIMESTAMP(NOW(),'-2:00:00');
```

七天后的日期

```sql
SELECT DATE_ADD(NOW(),INTERVAL 7 DAY);
SELECT DATE_ADD(NOW(),INTERVAL 10 MINUTE);
SELECT DATE_ADD(NOW(),INTERVAL 10 MONTH);
```

20 小时 10 分钟后的日期

```sql
SELECT DATE_ADD(NOW(),INTERVAL '20:10' HOUR_MINUTE);
```

2 天 8 小时后的日期

```sql
SELECT DATE_ADD(NOW(),INTERVAL '2 8' DAY_HOUR);
```

获取本月最后一天日期

```sql
SELECT LAST_DAY(now());
```

获取本月的第一天日期

```sql
SELECT DATE_SUB(now(),INTERVAL DAYOFMONTH(now())-1 DAY);
```

获取本月发表的文章

```sql
SELECT * FROM article
WHERE created_at >=DATE_SUB(now(),INTERVAL DAYOFMONTH(now()) DAY)
AND created_at <=LAST_DAY(now());
```

>*因为使用大量函数会造成性能下降，所以推荐在后台程序中算出时间后再进行比对*

获取三个月内发表的文章

```sql
SELECT * FROM article
WHERE publish_time >=DATE_SUB(now(),INTERVAL -3 MONTH) ;

# 如果从前上个月的一号开始获取
SELECT * from article
WHERE publish_time >= DATE_FORMAT(DATE_SUB(now(),INTERVAL 3 MONTH),'%Y-%m-01');
```

获取上个月的最后一天

```sql
SELECT LAST_DAY(DATE_SUB(NOW(),INTERVAL 1 MONTH));
# 或直接通过明确日期
SELECT * FROM article WHERE publish_time>='2019-01-01' AND publish_time<CURDATE();
```

下个月的第一天

```sql
SELECT DATE_ADD(LAST_DAY(NOW()),INTERVAL 1 DAY);
```

查看出生超过 20 年的同学

```sql
SELECT * FROM stu WHERE birthday < DATE_SUB(NOW(),INTERVAL 20 YEAR);
```

本周二的日期，使用 DAYOFWEEK 时周二为 3

```sql
SELECT now(),DATE_ADD(NOW(),INTERVAL 3-DAYOFWEEK(NOW()) DAY);
```

本周星期日

```sql
SELECT date_add(now(),INTERVAL 6-WEEKDAY(now()) DAY)

SELECT date_add(now(),INTERVAL 1-DAYOFWEEK(now())+7 day)
```

上周的星期日

```sql
SELECT date_add(now(),INTERVAL 1-DAYOFWEEK(now()) day)
```

查看三周前的周二

```sql
SELECT now(),
DATE_SUB(DATE_ADD(NOW(),INTERVAL 3-DAYOFWEEK(NOW()) DAY),INTERVAL 21 DAY);

# 或
SELECT date_add(now(),INTERVAL 3-DAYOFWEEK(now())-21 DAY )
```

上周一的日期

```sql
SET @week = DATE_SUB(NOW(),interval 1 week);
SELECT DATE_ADD(@week,INTERVAL 0-WEEKDAY(@week) day);

```

获取本月迟到的同学

```sql
select * from attendance
WHERE created_at >= date_sub(NOW(),INTERVAL DAYOFMONTH(now())-1 DAY)
AND time(created_at)>'08:30:00';
```

本月迟到超过 2 次的同学

```sql
select stu_id from attendance
WHERE created_at >= date_sub(NOW(),INTERVAL DAYOFMONTH(now())-1 DAY)
AND time(created_at)>'08:30:00'
GROUP BY stu_id
HAVING count(id)>=2;
```

本周周一的日期

```sql
SELECT DATE_ADD(now(),INTERVAL 0-WEEKDAY(now()) day);
```

获取本周迟到的学生编号

```sql
set @begin =DATE_FORMAT(date_add(now(),INTERVAL 0-WEEKDAY(now()) day),'%Y-%m-%d');
select stu_id from attendance
WHERE created_at >= @begin
AND time(created_at)>'08:00:00'
GROUP BY stu_id;
```

获取上周打卡记录

```sql
set @week = DATE_SUB(now(),INTERVAL 1 WEEK);
SELECT stu_id FROM attendance
WHERE created_at>=DATE_ADD(@week,interval 0-WEEKDAY(@week) day)
AND created_at<=DATE_ADD(@week,interval 4-WEEKDAY(@week) day);
```

获取本周发表的文章

```sql
SELECT * FROM article WHERE created_at >=DATE_ADD(now(),INTERVAL 0-WEEKDAY(now()) day);
```

周日来校学习的同学

```sql
SELECT * from attendance
WHERE date(created_at) = date(date_add(now(),INTERVAL 6 - WEEKDAY(now()) day));
```
